Cómo se instala el sistema operativo en un celular Android y en un iPhone

Un celular no se formatea e instala como un computador. El sistema viene grabado de fábrica y después se actualiza o se reinstala por caminos que controla el fabricante. Esta infografía resume esos caminos para Android y para iOS a partir de la documentación oficial de Google y de Apple.

Resumen

A diferencia de un computador personal, en un teléfono inteligente el usuario casi nunca instala el sistema operativo desde cero: el equipo sale de fábrica con el sistema grabado en su memoria flash y, a lo largo de su vida útil, se actualiza o se reinstala por rutas controladas por el fabricante. Esta infografía describe cómo ocurre ese proceso en las dos plataformas dominantes. En Android, un proyecto de código abierto que cada fabricante adapta, la instalación consiste en escribir imágenes en particiones verificadas por el cargador de arranque (Android Open Source Project, s.f.-b). En iOS, Apple controla el hardware y el software y autoriza cada instalación para un equipo concreto mediante una cadena de arranque seguro (Apple, s.f.-b). Se presentan los conceptos básicos, la arquitectura de cada sistema, el arranque verificado, las tres rutas de instalación de cada plataforma y una comparación entre ambas.

Palabras clave: sistema operativo móvil, Android, iOS, bootloader, actualización OTA, arranque verificado, firmware.

Análisis comparativo

El objetivo de ambas plataformas es el mismo —ejecutar un sistema auténtico y funcional—, pero lo logran con filosofías opuestas: apertura y diversidad de fabricantes en Android, integración vertical y control en iOS.

Conclusiones

  1. La instalación de un sistema operativo móvil difiere de la de un computador: el sistema viene grabado de fábrica y luego se actualiza o se reinstala por rutas que define el fabricante.
  2. El arranque verificado es el principio común de ambas plataformas: cada etapa comprueba con firmas digitales la siguiente, lo que impide ejecutar sistemas alterados.
  3. Android, por ser abierto, permite flashear imágenes, volver a versiones anteriores e instalar sistemas alternativos, a cambio de riesgos como la pérdida de datos o un equipo inservible.
  4. iOS ofrece un proceso más sencillo y uniforme gracias a la integración de hardware y software, pero limita al usuario a las versiones que Apple firma.
